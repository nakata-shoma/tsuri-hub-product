KEY FEATURE キーフィーチャー

フルソリッドブランクスが体現するアングラー主導のベイトジギング。

100ｍを超える水深、ヘビーウェイトのジグ、マグロ類など大型魚との真っ向勝負。トンジギをはじめ、ここ数年オフショアアングラーの注目を集めているベイトジギングは、スリルとリスクが同居する過酷な世界です。本来なら軽さや操作性に優れたチューブラーが主役となるこのジギングゲームにシマノがフルソリッドブランクスを導入した目的は、体力の消耗を極力抑え、スリリングなファイトをアングラー主導で展開することにありました。同一パワーであれば中空構造のチューブラーより細く作ることができ、強度にも優れる特性を持つフルソリッドは、その柔軟さゆえロッドを立ててのファイトが容易。強烈な引きにのされることなく安定したバランスを保てることで、長時間のやり取りにおいても疲労を軽減できる優位性があります。しかし、柔らかさのみにフォーカスしたソリッドではその効果は半減、むしろ逆効果とさえ言えるでしょう。アングラー有利のゲームを展開するためには、ソリッドの弱点と言われるネジレやパワーロスを解消したうえで、ジグを意のままに動かす操作性と反発力、さらには強靭な復元力も持ち合わせたブランクスが大前提となるからです。シマノはこの課題を克服し、極限まで曲げ込むことのできる粘り強さと、大型魚をも難なく浮かすリフティングパワーの両立を果たしました。シマノの先進テクノロジーを結集して生まれたゲームタイプJ フルベンドのブランクスは、アングラーに安心感をもたらし、エキサイティングでストレスフリーなベイトジギングを演出します。

 

高強度素材をさらに補強。ソリッドの概念を一新するハイパワーXフルソリッド構造。

ゲームタイプJ フルベンドのブランクスには高強度ソリッド素材タフテック∞を採用し、それをカーボンテープで重ね巻きするハイブリッド設計によって補強。ソリッド単体では実現できない細さと軽さを追求しています。さらに最外層をカーボンテープでX状に強化するハイパワーXフルソリッド構造を施すことで、フルソリッドの弱点とされるブレ、ネジレ、パワーロスといった不快なフィーリングを徹底的に抑制。ネジリ剛性が大幅に向上し、どこまで曲げ込んでも損なわれない粘り強さと高負荷にもへこたれない体幹の強さを両立しています。青物、マグロ、回遊魚、タチウオ、アカムツ、マス類etc. フルソリッドの概念を一新する高次元のブランクスが、様々なターゲットの攻略に新たな可能性を提案します。

 

【曲げ実験映像】オシアジガーフルベンド【ジギング】

※こちらは同構造を採用したオシアジガーフルベンドの映像です。

 

ベイトジギングをくまなくカバーするゲームタイプJシリーズ。

フルベンドの登場によって、いっそう強力な布陣となったゲームタイプJのベイトジギングロッド。チューブラーモデルのタイプJ、同じくチューブラーモデルのタイプスローJ、フルソリッドモデルのタイプJフルベンドと合計20アイテムに迫るラインナップは、近海から遠征まで広範にわたるベイトジギングをくまなくカバーしています。一般的に中空構造のチューブラーは軽さ・感度・操作性に優れ、シャープかつクイックなルアー操作やアタリの伝達能力を重視する釣りに向くとされています。いっぽうソリッドは芯まで詰まった構造で、チューブラーに比べて軽さや感度の面では劣りますが、柔軟性に優れるためアタリを弾きにくく、追従性や食い込みを重視する釣りに向いています。フォールに特化し、スローからミドルのジャークスピードを得意とする「タイプスローJ」、アグレッシブなジグ操作を身上とし、ミドルからハイスピードで持ち味を発揮する「タイプJ」、ジグのタイプやアクション、速度域に関わらずオールラウンドに対応可能な「タイプJフルベンド」。異なる個性を持つ3つのシリーズで、無限の可能性に満ちた快適なベイトジギングをお楽しみください。

IMPRESSION インプレッション

ワンピッチのなかでスピード変化をつけて誘うような使い方に最適のフルソリッドロッド。

人気のフルソリッドロッド、オシアジガー フルベンドをより手にしやすく、というコンセプトでリリースされたのがゲーム タイプJ フルベンドです。ワンピッチワンジャークで気持ちよくシャクることができるフルソリッドロッド、というのが第一印象です。ワンピッチのなかでスピード変化をつけて誘うような使い方には最適のロッドだと思います。

ブランクスにはハイパワーXフルソリッドを採用しています。ブレやパワー不足といったフルソリッドならではのデメリットを抑えているところはオシアジガー譲りです。ジグの操作性も高いですね。曲がり込んでいくブランクスですが、反発力はしっかり保持しています。ゲームならではの中弾性寄りのカーボン素材を用いているので、思い切り曲げ込んだときに感じる粘り強さや安心感はオシア以上といってもいいかも知れません。

基本的にはワンピッチワンジャークで使うと気持ちがいいロッドですが、スロー系ジギングに対応できる性能も十分にあります。肘当てジャークをやりやすい、上部がフラットになっていて安定感のあるリアグリップを採用しているので、快適にスロー系ジギングを展開できます。

違和感なく、気持ちよくジャークできるフルソリッドロッドという点が一番の魅力です。ラインナップも1パワーから5パワーまで幅広く、ライトジギングから中深海まで対応するアイテムが揃っています。青物ジギング、トンジギなどのマグロ狙いのジギングにも最適です。ジギングに慣れた方はもちろん、初心者の方にもオートマチックに快適に使ってもらえると思いますよ。

FEATURE 特徴

フルホールディングシート

高精度の操作をサポート。

先端を細くした形状やくびれ加工により吸い付くようなフィット感と疲れ知らずの握りごこちを追求し、握る、手のひらに乗せる、2〜4フィンガーなど、さまざまな持ち方に適応します。また、グリップの下部を平らにすることで握ったときの安定性を向上させ、高精度のジギングを手元からサポート。さらにカーボン強化素材CI4+を採用することで、軽量化と高感度化を図っています。

フラット仕様リアグリップ

肘当てジャークの安定性を高めるフラット仕様リアグリップ。

リアグリップは肘当てジャークをより快適に操作できるフラットデザインを採用。繰り返しの上下方向のジャークに対して肘当ての安定性に優れ、ジャークの精度が高まるだけでなく疲労やストレスを低減。確実なジグアクションの演出をサポート。

CI4+
