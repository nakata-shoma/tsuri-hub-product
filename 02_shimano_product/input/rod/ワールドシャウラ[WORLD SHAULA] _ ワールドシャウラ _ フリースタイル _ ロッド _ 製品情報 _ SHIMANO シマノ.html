KEY FEATURE キーフィーチャー

世界が、相手だ。

日本の、そして世界のフィールドを駆けて辿り着いたバーサタイルの新たな境地、ワールドシャウラ。

真紅の衝撃が走る。

 

バスフィッシングは、世界中のルアーターゲットと繋がっている。

日本のバスシーンを牽引してきた「スコーピオン」シリーズから生まれ、シマノバスロッドの最高峰として君臨してきた「シャウラ」が、バスだけでなく、日本、そして世界中のルアーターゲットと闘うために「ワールドシャウラ」として新たな生を受けてから約10年…。

どんなフィールドにも持ち運べる携行性のよさを考慮し、仕舞寸法130cmで統一された2or3ピース構造。素材に妥協することなく軽さと感度、パワーを追求した強靭なブランクス。そして、幅広いシチュエーションに対応するバーサタイル性。そのすべてにさらなる磨きをかけ、2018シーズン、いよいよその第二章が幕を開ける。

「長年温めていたアイディアを盛り込み、様々なゲームにより深く突っ込み、よりフィットするロッドが完成しました」

ワールドシャウラを総括するのはご存知ミスタースコーピオン、村田基。このロッドには、世界中の魚と格闘してきた彼の知見が随所に反映されている。

トリガー交換可能な新機構Xシート、キャステイングからバーチカルへ1本のロッドでマルチに対応できるエクステンションバット、高強度素材でブランクスにさらなる強さを与えるスパイラルXコア、軽量高感度を実現するカーボンモノコックグリップ、そして、スコーピオンの血統を証明する艶やかなレッド…。

あらんかぎりの技術を注ぎ込み、持つ喜びをも与えてくれる優美なデザインを与えられたワールドシャウラは、ルアーフィッシングロッドの新たな在り方と真のバーサタイルを体現する。

ノーマルグリップからロングタイプのエクステンションバットに交換することで、ジギング時のホールド性が格段にアップする。

 

 

キャストからバーチカルへ、バット交換でスピーディに対応。

6フィート台までのロッドはベイト、スピニングともに別売のエクステンションバットに対応した「バット交換モデル」。

キャスティングゲームからジギングなどのバーチカルゲームまで、1本のロッドで対応が可能です。

*TypeA, TypeB 適合リール：オシアジガー1000～1500番、オシアコンクエストシリーズ、オシアカルカッタシリーズ
*TypeC適合リール：スピニングリール1000～6000番サイズ

 

高強度素材で深化した次世代の基本構造

SPIRAL X CORE

［スパイラルXコア］

シマノ独自の設計・製造方法により、曲げ、ネジレ、つぶれなど、あらゆる方向に対して、さらなる高強度化を徹底追求。

ロッド性能を根幹から高めるシマノ独自の基本構造であるスパイラルXに、ナノアロイ®テクノロジー等の高強度材を用いたカーボンテープを使用。

選りすぐりの素材でさらなる高強度化を実現しました。

ネジレをさらに押さえ込む独自の強化構造。

HI-POWER X

［ハイパワーX］

ロッド全身をさらに補強する強化構造がこのハイパワーX。

キャスト時やファイト時に発生するネジレ現象を抑制するシマノ独自の構造です。

スパイラルXの最外層、あるいはカーボンシート縦横交差のノーマル構造の上からカーボンテープをX状に締め上げていくのが特長。

この構造によりネジレに対する剛性と強度が向上。

ブランクスが持つ本来の性能が発揮され、キャスト精度向上や飛距離アップにつながり、ファイト時にも優れた安定感を発揮します。

 

感度の基準を変えた中空構造が生んだ“軽さ”と“高感度”。

CARBON MONOCOQUE GRIP

［カーボンモノコックグリップ］

中空構造によって軽量化と振動伝達性を大幅に向上させた、カーボン一体成型リアグリップ。

振動の減衰を抑制し、水中情報を鮮明に伝える。

グリップエンドが軽くなることで操作時の慣性が低下し、レスポンスのよいロッドワークが可能です。

ワールドシャウラのスピニングロングモデルのカーボンモノコックグリップは、大物とのファイト時に肘に当てやすく、滑りにくいオリジナルデザインを採用。

 

手の大きさやフィッシングスタイルに応じてトリガーを好みの位置に変えられる新機構。

X SEAT

［エックスシート］

手の大きさやパーミングのスタイル、セットするリールによって、同じロッドでも最適なトリガー位置は変わってきますが、従来はアングラー側がロッドに持ち方を合わせるしかありませんでした。

ワールドシャウラのベイトキャスティングモデル（7フィート）に採用されたXシートは、リールシート後端を緩めるだけで簡単にトリガーの着脱交換が可能な新機構。

別売の夢屋Xシートカスタムトリガーとの交換であらゆるシチュエーションに適応し、タックルとの一体感をさらに向上させます。
